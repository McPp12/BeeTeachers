# BeeTeachers
 Sistema de Tutores y Asesorías Académicas (DICIS / UG) es una plataforma web y aplicación instalable (PWA) 100% gratuita diseñada para conectar a los estudiantes de la universidad con tutores pares, profesores y asesores académicos, integrando el motor de detección de salones vacíos en tiempo real de DICIS-Tracker.
